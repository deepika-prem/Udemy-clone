# Udemy-clone
Udemy Clone 🎓

A simple Udemy-inspired course website clone built using basic HTML and CSS. This project focuses on creating a clean and responsive learning platform interface with sections like navigation bar, course categories, featured courses, and banner design.

Features
Responsive homepage layout
Navigation bar
Course cards section
Modern landing page design
Simple and clean UI
Built using only HTML & CSS
Technologies Used
HTML
CSS
Purpose

This project was created to practice frontend web development basics and improve HTML & CSS design skills by recreating a popular e-learning platform interface similar to Udemy.
